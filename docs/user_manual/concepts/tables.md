# Tables

The table component is one of the most central component in Overmind. Here we will expose all the main capabilities of this component to give you full powers for your productivity.

## Overview

The table component is composed of 6 main area :

![Table layout](/img/table_area.png)

1. Contextual actions area,
2. Filters management area,
3. Table groups and columns,
4. Table datas
5. Statistic management and informations area,
6. Pagination and configuration area.

## Customization

For each table you can customize how columns are displayed. Depending of the value displayed in the column there will be more or less options. Options are accessible with right click on the column name.

![Column actions](/img/column_actions.png)


The range of possible actions are the following :

- Sort column ascending or descending,
- Pin column to the righ or to le left, this will make the column always visible when scrolling horizontally,
- Group by allow to group rows by the values inside the column,
- Hide or show columns,
- Resize the width of the column.
