# Admin

## Impersonification

Vous avez besoin d'autorisation Admin pour accéder à cet outil.

Utilisez cet outil pour simuler une connection en tant qu'un autre user.
Vous pourez ainsi voir à quoi il à accès, et experimenter Yuzu en tant que cet utilisateur.
