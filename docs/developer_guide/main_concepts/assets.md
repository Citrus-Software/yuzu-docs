# Assets

Yuzu is construct around a central concept : `Asset`. Assets are organized following a tree hierarchie and all assets must have a parent asset. Then, over this base class, we defined asset types that we will be managing inside Yuzu. 

Here are the main `assets` types used in Yuzu : 

- Group: `gp`
- User: `us`
- Project: `pj`
- Folder: `fo`
- Model: `mo`
- Episode: `ep`
- Shot: `sh`

Other types less frequentrly used :

- Sequence: `sq`
- Computer: `pc`
- Location: `lc`
- Office: `of`
- Place holder: `ph`
